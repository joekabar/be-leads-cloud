# Plan: kbo-lookup skill + kbo_dump source (prompt 5)

## Goal

Ship the kbo-lookup skill (covers Open Data and kbopub) plus the kbo_dump source that ingests
a KBO Open Data ZIP (full or update) into the observations table with full provenance.

## Scope in

- Skill `SKILL.md` + references (open-data-schema.md, kbopub-selectors.md placeholder,
  checksum.md, samples/README.md)
- Source module `src/scraper/sources/kbo_dump/` (parser, transformer, ingester, downloader stub,
  cli)
- CLI `uv run be-leads-ingest-kbo --zip <path>` and `uv run be-leads-validate-kbo <number>`
- Tests: unit + integration with synthetic mini-ZIP fixture
- Updates to CLAUDE.md, agent_docs/runbook.md, CHANGELOG

## Out of scope

- kbopub HTML scraping (prompt 6)
- Actual SFTP downloader (requires account approval)
- Downloading a real KBO Open Data ZIP
- Changes to any pre-prompt-5 source module

## Acceptance criteria

1. Skill loads on KBO-related prompts.
2. Ingester processes 50-row synthetic ZIP into ≥200 observations tagged source=kbo_dump.
3. Idempotent on re-ingest (same ZIP twice → 0 new observations).
4. Supports both Full and Update ZIPs.
5. `mypy --strict` clean.
6. Coverage on `src/scraper/sources/kbo_dump/` ≥ 90%.
7. Integration test inserts to disposable test DB and verifies companies_current refresh works.

## Implementation order

1. Plan file (this file).
2. Skill directory: SKILL.md + reference docs.
3. Golden fixture CSVs.
4. Source module: parser → transformer → ingester → downloader stub → cli.
5. Tests: unit (parser, transformer) → integration (ingester, cli).
6. pyproject.toml script entries.
7. CLAUDE.md, runbook, CHANGELOG updates.
8. Verification run.
